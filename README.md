## ⚙️ منهجيتي في العمل

<div align="right">

```
جمع البيانات  →  تنظيف وتجهيز  →  تحليل استكشافي  →  نمذجة  →  تقديم النتائج
```

| الخطوة | الأدوات | الهدف |
| :--- | :--- | :--- |
| 🌐 **جمع البيانات** | Scrapy, Selenium, Proxies | استخراج آمن من المواقع الثابتة والديناميكية |
| 🧹 **تنظيف البيانات** | Pandas, NumPy | معالجة القيم المفقودة، التكرارات، التنسيقات |
| 🔍 **التحليل الاستكشافي** | Plotly, Matplotlib, SciPy | اكتشاف الأنماط واختبار الفرضيات |
| 🤖 **النمذجة والتنبؤ** | Scikit-learn, Groq API | انحدار، تصنيف، ARIMA، LLM |
| 📊 **تقديم النتائج** | Plotly Dashboards, Power BI | تقارير تفاعلية بالعربية والإنجليزية |
